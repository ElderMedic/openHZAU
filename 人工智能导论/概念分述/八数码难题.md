## 1. 什么是“八数码难题”（8-Puzzle）？

**八数码问题是人工智能中一个经典的状态空间搜索问题，主要用于研究如何通过搜索算法，从一个初始状态找到通往目标状态的最优路径。**

- **棋盘结构**：它由一个 $3 \times 3$ 的方格棋盘组成，上面有 8 个带有数字（1~8）的方块和一个空白格（通常用 0 或空格表示）。
    
- **操作规则**：玩家或算法可以将与空白格相邻的数字（上下左右）移动到空白格中。
    
- **目标**：通过一系列合法的移动，将初始的数字布局转变（重排）为给定的目标状态。

## **2. 为什么八数码问题属于搜索问题？**

因为我们不知道应该先移动哪个数字，也不知道需要移动多少次才能到达目标状态。我们可以把每一种数字排列看作一个**状态（State）**。以上图为例，假设空格在中间，那么它可以向上、下、左、右移动，产生最多四个新的状态。

![](images/file-20261115191710293.png)

如此不断扩展新状态，就会形成一棵搜索树：

- 根节点：初始状态。
    
- 子节点：当前状态经过一次合法移动得到的新状态。
    
- 目标节点：数字排列符合目标状态的状态。
    
- 路径：从初始状态到目标状态的一系列移动。

其他概念：

| 概念            | 含义                |
| ------------- | ----------------- |
| 状态（State）     | 当前八个数字和空格的排列      |
| 初始状态          | 题目给定的初始数字排列       |
| 目标状态          | 需要达到的数字排列         |
| 操作符（Operator） | 空格向上、下、左、右移动      |
| 状态空间          | 所有可能出现的状态集合       |
| 路径代价          | 从初始状态到当前状态所需的移动次数 |

对于八数码问题，9 个位置共有：$9!=362880$ 种排列。其中只有一半状态可以通过合法移动互相到达，因此实际可达状态数量为：$\frac{9!}{2}=181440$，这意味着搜索算法需要在大量可能状态中寻找目标。

搜索算法要解决的问题就是：**如何高效地找到目标节点，以及如何尽可能减少移动次数。**

## 3. 公式 $f(x) = d(x) + h(x)$ 的含义解析

这个公式是经典的 **$A^*$（A-Star）算法** 中用于评估节点优先级的**估价函数**。$A^*$ 算法通过综合考虑“已经付出的代价”和“预计还要付出的代价”来高效地寻找最优解。

- **$f(x)$（总估价值）**：
    
    - 代表通过节点 $x$ 到达目标状态的估计总代价（总搜索开销或总步数）。在每一步扩展节点时，算法会优先选择 $f(x)$ 值最小的节点进行扩展。
        
- **$d(x)$（历史代价 / 深度）**：
    
    - 代表从初始状态（根节点）到当前节点 $x$ 所实际走过的步数，也就是搜索树中的**深度**。这保证了我们追求最短路径。
        
- **$h(x)$（启发函数 / 预估代价）**：
    
    - 代表从当前节点 $x$ 到目标状态的**估计剩余代价**。
        
    - 在图片给出的具体定义中，$h(x)$ 指的是“不在位”的数码个数——即当前节点 $x$ 中，有多少个数字没有放在目标状态对应的位置上（不统计空白格）。
        
    - 这种启发函数简单直观：不在位的数字越多，说明离目标越远，$h(x)$ 就越大，从而指导搜索朝着正确的目标方向前进，避免盲目搜索。
