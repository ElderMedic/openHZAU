## 1. 如何理解这个“误差”？

在求解方程 $2X_1 + 3X_2 + X_3 = 20$ 时，遗传算法本身并不会做代数移项消元，它本质上是一个“盲目试错 + 优胜劣汰”的搜索器——不断随机生成一堆 $(X_1, X_2, X_3)$ 的组合往方程里代入去试。

- **误差的物理含义（距离目标的差距）**： 既然是往方程里代值试错，就需要一把尺子来衡量“这一组数猜得准不准”。 方程右边要求等于 $20$，我们把猜出来的 $(X_1, X_2, X_3)$ 代入左边算出来一个结果，两者相减并取绝对值：
    $$f(x) = \vert{}2X_1 + 3X_2 + X_3 - 20\vert{}$$
    - **个体 1** $(5, 3, 1)$ 代入左边等于 $20$，与目标 $20$ 相差 **$0$** —— 说明**完全猜中**，没有任何偏差。
        
    - **个体 2** $(3, 2, 4)$ 代入左边等于 $16$，与目标 $20$ 相差 **$4$** —— 说明**离正确答案还差 $4$ 的距离**。
        
    - 之所以要加**绝对值**，是因为无论是算出来 $16$（比 $20$ 小 $4$）还是算出来 $24$（比 $20$ 大 $4$），它们**偏离正确答案的程度**是一样的，都是偏差了 $4$ 个单位。
        

## 2. 为什么误差就是把原问题转化成另一个函数？

这背后是计算数学和人工智能中一个极其核心的思想：**将“方程求根（判断对错）”转化为“函数优化（比拼高低）”**。

### 原方程的问题：无法直接用于“优胜劣汰”

原来的等式 $2X_1 + 3X_2 + X_3 = 20$ 是一个**布尔逻辑判断**（只有“成立”和“不成立”两种状态，即“对”或“错”）。 如果在遗传算法中直接用原方程作为判断标准，就会出现如下问题：

- 假设种群里有 100 个随机生成的个体，全都没有凑出 $20$（全都是错的）。
    
- 原函数这个判断标准只能判断它们“全部淘汰（得分全为 0）”。这样算法就失去了进化方向——它无法知道 $(3, 2, 4)$（算出来 $16$，很接近 $20$ 了）其实比 $(0, 0, 1)$（算出来 $1$，离 $20$ 相去甚远）优秀得多，从而无法保留优秀基因去杂交出正确答案。

### 转化：用连续的“梯度坡度”代替“数值阶跃”

把等式移项写成误差函数 $f(x) = \vert{}2X_1 + 3X_2 + X_3 - 20\vert{}$，实质上是**把一个“找特定点”的死板等式，转变为一个“找最低谷”的地形函数**：

1. **量化“接近程度”**：即使两个个体都没命中答案，误差函数也能给出不同数值的适应度——误差为 $4$ 的个体比误差为 $19$ 的个体更接近谷底，适应度也就更高。
    
2. **指明进化方向**：遗传算法通过适应度函数 $F(c) = \frac{1}{1 + f(x)}$，把“误差越小”映射为“适应度越高”。在轮盘赌中，接近正确答案的个体就会获得更高的存活概率，通过几代交叉变异，种群就会顺着这个坡度一步步逼近误差 $f(x) = 0$ 的谷底。

**只要找到了让误差函数 $f(x)$ 取得最小值 $0$ 的自变量，也就等价于求出了原方程的解。** 这就是“方程求解问题”向“函数极值优化问题”的等价转化。
