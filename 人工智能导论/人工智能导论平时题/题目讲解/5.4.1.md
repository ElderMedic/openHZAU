## 遗传算法详细计算过程

### 1. 初始条件回顾

* **种群规模**：$N = 4$
* **编码方式**：二进制编码
* **适应度函数**：$f(x) = x^2$
* **初始种群**：
  * $\text{s01} = 1010$，$x = 10$
  * $\text{s02} = 0100$，$x = 4$
  * $\text{s03} = 1100$，$x = 12$
  * $\text{s04} = 0111$，$x = 7$

---

### 2. 第一问：选择操作计算

#### Step 1: 计算各个体的适应度 $f(x)$
* $\text{s01}: f(10) = 10^2 = 100$
* $\text{s02}: f(4) = 4^2 = 16$
* $\text{s03}: f(12) = 12^2 = 144$
* $\text{s04}: f(7) = 7^2 = 49$

**适应度总和** $\sum f(x) = 100 + 16 + 144 + 49 = 309$

#### Step 2: 计算选择百分比（概率）与累计百分比
* **$\text{s01}$**：
  * 百分比 = $\frac{100}{309} \approx 32.36\%$
  * 累计百分比 = $0.3236$
* **$\text{s02}$**：
  * 百分比 = $\frac{16}{309} \approx 5.18\%$
  * 累计百分比 = $0.3236 + 0.0518 = 0.3754$
* **$\text{s03}$**：
  * 百分比 = $\frac{144}{309} \approx 46.60\%$
  * 累计百分比 = $0.3754 + 0.4660 = 0.8414$
* **$\text{s04}$**：
  * 百分比 = $\frac{49}{309} \approx 15.86\%$
  * 累计百分比 = $0.8414 + 0.1586 = 1.0000$

#### Step 3: 轮盘赌选择
轮盘赌区间划分：
* $\text{s01}: [0, 0.3236]$
* $\text{s02}: (0.3236, 0.3754]$
* $\text{s03}: (0.3754, 0.8414]$
* $\text{s04}: (0.8414, 1.0000]$

依此生成的 4 个随机数分别为 `0.42`、`0.16`、`0.89` 和 `0.71`：
1. 随机数 `0.42` $\in (0.3754, 0.8414]$ $\rightarrow$ 选中 **$\text{s03}$**
2. 随机数 `0.16` $\in [0, 0.3236]$ $\rightarrow$ 选中 **$\text{s01}$**
3. 随机数 `0.89` $\in (0.8414, 1.0000]$ $\rightarrow$ 选中 **$\text{s04}$**
4. 随机数 `0.71` $\in (0.3754, 0.8414]$ $\rightarrow$ 选中 **$\text{s03}$**

* **选择后的种群**：`s03` (1100)、`s01` (1010)、`s04` (0111)、`s03` (1100)

---

### 3. 第二问：交叉操作计算

* **交叉参数**：$P_c = 1$（全部进行交叉），单点交叉，交叉点为 2，交叉顺序按个体在种群中的顺序。
* **变异参数**：$P_m = 0$（无变异）。

选中种群按顺序配对进行单点交叉（交叉点为 2，即从左往右数第 2 位后面断开，交换后半部分）：

1. **第一对**：`s03` 与 `s01`
   * 父代 1：`11 | 00`
   * 父代 2：`10 | 10`
   * 交换后子代 1：`11` + `10` = **`1110`**
   * 交换后子代 2：`10` + `00` = **`1000`**

2. **第二对**：`s04` 与 `s03`
   * 父代 3：`01 | 11`
   * 父代 4：`11 | 00`
   * 交换后子代 3：`01` + `00` = **`0100`**
   * 交换后子代 4：`11` + `11` = **`1111`**

* **得到的下一代种群**：`1110`、`1000`、`0100`、`1111`
